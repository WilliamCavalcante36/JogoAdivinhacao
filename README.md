Jogo da Adivinhação (Java)

Aplicação desktop desenvolvida em Java utilizando Swing, onde o usuário deve adivinhar um número aleatório entre 1 e 100.

Funcionalidades:
- Interface gráfica com Java Swing
- Geração de número aleatório
- Feedback em tempo real (maior/menor)
- Contador de tentativas
- Reinício automático ao acertar
- Estilização inspirada no estilo Frutiger Aero

Tecnologias

- Java
- Swing (GUI)
